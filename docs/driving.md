# 시티 드라이브 — 웹 버전 기획서

- 상태: 초안 (확인 필요 항목은 10장)
- 대상: 1단계 웹 버전. Unreal Engine 5 본 제작(2단계)은 이 문서 범위 밖이다.

## 1. 컨셉

실제 한국 도시의 지도를 바탕으로 만든 거리에서, 목표도 경쟁도 없이 좋아하는 차로 달리는 **현실적인 드라이빙 시뮬레이션**. 레이싱 게임이 아니다.

고층 빌딩이 늘어선 도심에서 출발해, 굽은 언덕길을 넘어, 한적한 시골길까지 한 번에 이어서 달릴 수 있다. 라디오를 틀어 놓고.

## 2. 핵심 경험

기능을 넣을지 말지는 아래 네 가지에 도움이 되는지로 판단한다.

1. **현실적인 운전 감각** — 차의 무게, 가속과 제동의 쏠림, 오르막과 내리막, 속도에 따라 달라지는 핸들 반응. 과장하지 않는다.
2. **실제 같은 한국 거리** — 실제 도로 선형과 건물 배치, 한국식 차선·표지판·간판·아파트 단지.
3. **구간마다 다른 분위기** — 도심, 굽은 길, 시골길이 뚜렷하게 구분되고, 날씨와 시간에 따라 다시 달라진다.
4. **부담 없음** — 실패, 점수, 제한 시간이 없다. 링크를 열면 바로 달린다.

## 3. 무대: 실제 지도 기반

### 3.1 지역 선정 조건

- 현대적 고층 도심, 굽은 길, 시골 같은 길이 **서로 가까이** 붙어 있을 것 (한 번의 주행으로 이어져야 한다)
- 공개 지도 데이터의 도로·건물 정보가 충분할 것
- 달리는 풍경이 좋을 것

### 3.2 확정 지역: 부산 해운대 ~ 달맞이길 ~ 기장

| 구간 | 실제 장소 | 성격 |
|---|---|---|
| 고층 도심 | 마린시티, 센텀시티, 해운대 해변로 | 초고층 주상복합, 넓은 대로, 상가 거리 |
| 굽은 길 | 달맞이길 (해운대 ~ 송정) | 바다를 낀 언덕 위 굽은 2차로 |
| 시골길 | 송정 ~ 기장 일대 | 해안 마을, 논밭 사이 좁은 길, 낮은 건물 |

세 구간이 약 10km 안에 이어져 있고 바다가 계속 보인다. 힐링 드라이브라는 목적에 가장 잘 맞는다.

**대안**

| 지역 | 장점 | 단점 |
|---|---|---|
| 서울 강남 ~ 남산 ~ 북악스카이웨이 | 가장 익숙한 고층 도심, 굽은 산길 | 시골길이 멀다. 건물 밀도가 높아 데이터와 성능 부담이 크다 |
| 제주 제주시 ~ 해안도로 ~ 중산간 | 풍경이 가장 좋다, 시골길 풍부 | 고층 도심이 약하다 |

### 3.3 규모

| 단계 | 범위 | 목적 |
|---|---|---|
| 첫 공개 | 고층 도심 약 2km × 2km | 실제 지도로 도시가 만들어지는지 검증 |
| 확장 1 | 달맞이길 구간 추가 | 굽은 길과 고저차 |
| 확장 2 | 송정 ~ 기장 일부 추가 | 시골길 |

처음부터 전체를 만들지 않는다. 지도 변환 과정이 가장 불확실하므로 작은 영역에서 먼저 검증한다.

### 3.4 지도 데이터

| 데이터 | 출처 | 비고 |
|---|---|---|
| 도로, 건물 윤곽, 토지 이용, 수역 | OpenStreetMap | 무료. 화면에 출처 표기 의무(ODbL) |
| 지형 고도 | 공개 수치표고모델 (SRTM 등) | 무료. 해상도가 낮아 도로 주변은 보정 필요 |
| 건물 높이 | OpenStreetMap의 높이·층수 정보 | 한국은 누락이 많다. 없는 건물은 용도와 면적으로 추정 |

국토교통부 브이월드, 국가공간정보포털의 건물 데이터는 더 정확하지만 이용 조건 확인이 필요하다. 1단계에서는 OpenStreetMap만으로 시작하고, 높이 품질이 문제가 되면 검토한다.

**실제와 다르게 하는 것**

- 실제 상호와 브랜드 간판은 쓰지 않는다. 가상의 상호로 한국식 간판을 만든다.
- 지명과 도로명은 실제 이름을 쓴다.
- 건물 외관은 실제 건물을 재현하지 않는다. 윤곽과 높이만 실제이고, 외벽은 유형별(오피스, 주상복합, 아파트, 상가, 단독주택)로 자동 생성한다.

## 4. 주행

### 4.1 원칙

- 시내 속도(30~80km/h)에서 자연스러워야 한다.
- 키보드로도 부드럽게 몰 수 있어야 한다. 입력은 서서히 들어가고 속도가 높을수록 조향각이 줄어든다.
- 오르막에서는 힘이 부치고 내리막에서는 속도가 붙는다.
- 빗길과 눈길은 체감될 만큼 미끄럽다.
- 한국 도로 기준: 우측통행, 좌측 운전석, 실제 차로 폭.

### 4.2 차량

| 차량 | 구동 | 성격 |
|---|---|---|
| 시티 해치백 | 전륜 | 가볍고 다루기 쉽다 |
| 비즈니스 세단 | 전륜 | 안정적이고 균형 잡혔다 |
| 스포츠 쿠페 | 후륜 | 빠르지만 미끄러지기 쉽다 |
| 패밀리 SUV | 사륜 | 무겁고 많이 기울며 시야가 높다 |

모두 가상 차량이다. 색상을 고를 수 있다.

### 4.3 조작과 시점

- 가속, 제동, 조향, 핸드브레이크, 후진, 자동 변속
- 방향지시등, 전조등, 경적
- 키보드와 게임패드
- 3인칭 추적 시점, 운전석 시점(계기판, 핸들, 룸미러)

### 4.4 화면 정보

속도계, 기어, 회전수, 현재 도로명과 제한속도 표시, 미니맵. 제한속도를 넘어도 벌점은 없다.

## 5. 한국풍 거리

| 요소 | 내용 |
|---|---|
| 노면 | 황색 중앙선, 백색 차선, 횡단보도, 정지선, 유턴 표시, 어린이보호구역 노면 표시, 과속방지턱 |
| 시설물 | 한국식 신호등(가로형), 도로 표지판(녹색·청색), 가로등, 전봇대와 전선, 버스 정류장, 가드레일 |
| 건물 | 유리 외벽 고층 오피스, 초고층 주상복합, 판상형 아파트 단지, 간판이 층층이 붙은 상가 건물, 시골 단층 주택 |
| 간판 | 한글 세로·가로 간판, 밤에는 발광 |
| 자연 | 가로수(은행나무·벚나무), 야산, 논밭, 바다 |

신호등은 켜지고 바뀌지만 1단계에서는 지키지 않아도 된다.

## 6. 날씨와 시간

- 날씨: 맑음, 흐림, 비, 안개, 눈
- 시간: 새벽, 낮, 노을, 밤
- 주행 중에 바꿀 수 있다.
- 비: 빗줄기, 젖은 노면 반사, 앞유리 빗방울과 와이퍼(운전석 시점), 빗소리
- 밤: 창문 불빛, 간판, 가로등, 전조등
- 접지력은 날씨에 따라 달라진다.

## 7. 라디오와 음악

### 7.1 방식

상용 음악은 저작권 때문에 게임에 넣거나 임의로 스트리밍할 수 없다. 아래 두 가지를 제공한다.

| 방식 | 내용 |
|---|---|
| 내장 라디오 | 자유 이용 허락 음원(CC0, CC BY 등)으로 구성한 채널. 로파이, 시티팝풍, 재즈, 어쿠스틱처럼 분위기별로 나눈다 |
| 내 음악 | 플레이어가 자기 컴퓨터의 음악 파일을 끌어다 놓으면 재생한다. 파일은 서버로 전송되지 않는다 |

### 7.2 라디오다운 느낌

- 채널을 돌리면 지직거리는 소리가 잠깐 난다.
- 방송처럼 곡이 이미 흘러가는 중간부터 들린다.
- 터널에 들어가면 수신이 약해진다.
- 운전석 시점에서는 차 스피커로 듣는 것처럼, 바깥 시점에서는 창 너머로 새어 나오는 것처럼 들린다.
- 엔진음, 빗소리와 음량을 각각 조절할 수 있다.

### 7.3 음원 확보 원칙

곡마다 출처와 이용 조건을 기록한다. 저작자 표시가 필요한 곡은 게임 안 "크레딧" 화면에 표기한다.

## 8. 공유와 성능

- 설치 없이 링크만 열면 실행된다. 무료 정적 호스팅에 올린다.
- 지도는 구역 단위로 나누어, 차가 가까이 가면 내려받는다. 처음 뜨는 시간을 짧게 유지한다.
- 그래픽 품질 3단계(낮음·보통·높음)를 두고 기기에 따라 자동 선택한다.
- 목표: 외장 그래픽이 있는 PC에서 60프레임, 일반 노트북에서 30프레임 이상.
- PC 브라우저를 우선한다. 모바일은 1단계 범위 밖이다.

## 9. 제작 순서

각 단계가 끝나면 링크로 공유할 수 있는 상태여야 한다.

| 단계 | 내용 | 끝났다고 보는 기준 |
|---|---|---|
| 0. 지도 검증 | 추천 지역 약 1km × 1km를 지도 데이터에서 변환해 도로·건물·지형을 화면에 띄운다 | 실제 지도와 대조해 도로와 건물 위치가 맞는다. 안 되면 지역이나 방식을 바꾼다 |
| 1. 주행 | 실제 도로 위에서 4종 차량 주행, 경사 반영, 충돌, 두 가지 시점, 계기판 | 도심 한 바퀴를 막힘 없이 돈다 |
| 2. 거리 꾸미기 | 차선·표지판·신호등·간판·가로수, 건물 유형별 외벽 | 화면만 보고 한국 도시로 느껴진다 |
| 3. 날씨와 시간 | 날씨 5종, 시간 4종, 접지력 연동 | 모든 조합이 정상으로 보인다 |
| 4. 라디오 | 내장 채널, 내 음악, 음량 조절, 크레딧 | 주행 중 채널을 바꾸며 들을 수 있다 |
| 5. 확장과 공개 | 굽은 길·시골길 구간 추가, 구역 단위 내려받기, 품질 옵션, 배포 | 도심에서 시골길까지 끊김 없이 이어서 달린다 |

### 1단계 웹 버전에서 넣지 않는 것

다른 차량과 보행자, 교통 법규 위반 판정, 미션·점수, 차량 파손, 멀티플레이, 저장 기능, 모바일 조작, 실제 브랜드 차량과 상호.

## 11. 위험 요소

| 위험 | 영향 | 대응 |
|---|---|---|
| 지도 데이터에서 교차로·고가도로·터널을 자연스럽게 만들기 어렵다 | 도로가 어색하거나 끊긴다 | 0단계에서 먼저 검증한다. 문제 구간은 수작업으로 보정한다 |
| 건물 높이 정보 누락 | 스카이라인이 실제와 다르다 | 추정 규칙을 쓰고, 눈에 띄는 대표 건물만 직접 입력한다 |
| 고도 데이터 해상도가 낮다 | 도로가 울퉁불퉁하거나 지형에 묻힌다 | 도로를 따라 고도를 매끄럽게 다듬고 지형을 도로에 맞춘다 |
| 건물이 많아 브라우저에서 느려진다 | 프레임 저하 | 구역 단위 내려받기, 먼 건물 단순화, 품질 옵션 |
| 쓸 만한 자유 이용 음원 부족 | 라디오가 빈약하다 | "내 음악" 기능으로 보완한다 |

## 12. 0단계 결과: 지도 검증 (2026-11-22)

대상은 해운대 마린시티 일대 1km × 1km다. `npm run map:fetch`, `npm run map:build`로 지도 파일을 만들고, `npm run dev` 후 `/map.html`에서 확인한다.

**결론: 이 방식으로 진행한다.** 도로와 건물은 실제 지도와 맞는다. 고도와 해안선은 보완이 필요하다.

| 항목 | 결과 | 판정 |
|---|---|---|
| 도로 위치 | 기준 지도를 겹쳤을 때 차도가 지도의 도로 위에 정확히 놓인다. 회전교차로 모양도 일치 | 통과 |
| 거리 축척 | 변환한 거리와 지구 곡면 거리의 차이 0.2% 이내 | 통과 |
| 건물 | 125동 중 높이 실측값 46동, 층수 환산 72동, 추정 7동. 제니스 A동 300m로 실제와 일치 | 통과 |
| 도로 정보 | 차도 14.6km, 193구간. 차로 수는 18구간, 제한속도는 4구간에만 있다 | 보완 필요 |
| 고도 | 원본 그대로는 쓸 수 없다. 고층 건물이 지형으로 찍혀 평지 도로의 경사가 중앙값 3.4%, 상위 5%는 16.6% 이상으로 나온다. 필터를 거치면 1.1%, 5.9%로 줄어든다 | 보완 필요 |
| 해안선 | 고도 데이터로는 바다와 땅을 구분할 수 없어 지도의 해안선으로 판정했다. 검증 구역 안은 맞고, 구역 바깥 가장자리는 일부 틀린다 | 보완 필요 |
| 교량 | 4구간(광안대로 등)의 높이 정보가 없다. 임시 높이로 표시했다 | 미해결 |

**1단계에 반영할 것**

- 차로 수와 제한속도는 도로 등급별 기본값을 쓴다. 눈에 띄게 틀린 곳만 직접 고친다.
- 지형은 도로를 기준으로 다듬는다. 도로를 따라 고도를 매끄럽게 하고 주변 땅을 도로에 맞춘다.
- 해안선은 선이 아니라 닫힌 육지 영역으로 만들어 판정한다.
- 달맞이길처럼 경사가 중요한 구간에 들어가기 전에, 건물이 제거된 국내 고도 자료(국토지리정보원 수치표고모델)를 쓸 수 있는지 확인한다.

- 지하차도(터널 표시 6구간)는 지상 도로로 그려진다. 고가도로·교량 41구간은 여전히 올라갈 수 없다.
- 한번 불러온 구역은 내리지 않는다. 지도가 더 커지면 멀어진 구역을 내리는 처리가 필요하다.
- 추정 건물은 건물 네 귀와 가운데만 검사해 놓으므로 드물게 보행로나 하천과 겹칠 수 있다.
- 0단계의 지도 검증 뷰어(`map.html`)는 지도 형식이 바뀌어 없앴다. 확장 구역은 실제 지도와 눈으로 대조하지 않았다(좌표 변환식은 0단계에서 검증한 것 그대로다).

## 18. 현재까지 만든 것

- 지도는 `public/map/haeundae/`의 `base.json`(도로·고도·땅/바다·구역 표)과 구역 파일 65개. `npm run map:fetch`, `npm run map:build`로 다시 만든다.

- 라디오: `src/radio.js`, `tools/build-radio.mjs`, `public/radio/`.

- 날씨와 시간: `src/atmosphere.js`(하늘·빛·안개·비·눈·전환), `src/reflection.js`(젖은 노면 반사), `src/windshield.js`(앞유리), `src/map/shared.js`(눈·젖은 노면·창문 불빛 공용 처리).

- 거리 꾸미기: `src/map/street.js`(노면·인도·신호등·표지·나무), `src/map/facades.js`(외벽·간판), `src/map/network.js`(교차로 분석).

- 게임 본체: `index.html`, `src/main.js`(화면·입력·카메라), `src/world.js`(지도에서 만든 세계, 충돌, 도로 조회), `src/vehicle.js`·`src/cars.js`(차량), `src/audio.js`(엔진음).
- 지도 변환 도구(`tools/`)와 지도를 읽어 지형·도로·건물을 만드는 코드(`src/map/`).

- 격자형 가상 도시 계획은 폐기했다.
